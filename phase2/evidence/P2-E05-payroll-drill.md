# P2-E05 — Synthetic payroll fallback drill

**FICTIONAL EXERCISE, NOT A REAL TEST.** Scenario date: 2026-11-19.

Using 120 fabricated employee records, export took **36 minutes**, alternative import **67 minutes**, reconciliation **13 minutes** = **116 minutes**, within the assumed four-hour recovery objective. All 120 fictional records reconciled.

A faster fallback reduces *impact*, not outage likelihood. R-004 changes from likelihood 3 / impact 4 to likelihood **3** / impact **2** = **6 Medium**. Repeat exercises and real business approvals would be needed outside this simulation.
